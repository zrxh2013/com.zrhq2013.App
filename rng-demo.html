老虎机 RNG 原理与概率演示

通过可复现的随机数实验，看清三件事：旋转结果怎么产生、免费游戏的间隔服从什么分布、为什么任何"触发时间预测器"都不可能有效。

本工具中的麻将牌面仅为视觉装饰，模拟基于公开的概率模型，与任何具体游戏及其内部参数无关。网络赌博在中国大陆属于违法行为，兜售"爆分/触发预测软件"是常见诈骗。

① RNG（随机数生成器）是怎么工作的

正规老虎机每次旋转在你点击的瞬间向 RNG 取一个（或一组）随机数，服务器端据此确定结果。旋转动画只是"开奖结果"的播放过程，不影响结果。

A. 伪随机数（PRNG）：种子决定一切

游戏程序常用确定性算法（如下面的 mulberry32）。同样的种子，必然产生同样的序列——所以种子必须由系统安全熵（时间、硬件噪声等）注入，玩家无法从外部观察到。

function mulberry32(a){ return function(){ a |= 0; a = a + 0x6D2B79F5 | 0; let t = Math.imul(a ^ a >>> 15, 1 | a); t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t; return ((t ^ t >>> 14) >>> 0) / 4294967296; // [0,1) } }

序列 B

观察：相同种子 → 两列逐位相同（确定性）；不同种子 → 毫无关系。真实平台通常使用加密安全随机源（CSPRNG）或服务器种子+哈希承诺方案，客户端历史记录无法反推种子。

B. 一个 [0,1) 随机数如何变成牌面

转轮条带上每个符号有权重。把权重累加起来划分区间，随机数落进哪个区间，就开出哪个符号——这叫"加权抽样 / 虚拟转轮"。

免费游戏（Scatter）触发则是另一个独立的随机判定：u < p 即触发，与转轮上看到了什么、上一局结果如何，全都无关。

为什么"看记录预测"在数学上不成立

  • 独立性：每次旋转是独立抽取，过去的序列不含未来的信息（熵不来自历史）。
  • 无记忆性：已经连续 100 次没触发，不会让第 101 次"更该出"——它的概率还是 p。
  • 状态不可见：PRNG 的内部状态/种子在服务器端，你拿到的几百个开奖结果不足以重建状态（对 CSPRNG 而言，即使拿到海量输出也无法预测）。
  • 小样本错觉："连出 3 次""很久没出"在百万次尺度上天天发生，不是规律，是几何分布的正常现象。

② 免费游戏触发间隔 = 几何分布

设每次旋转触发免费游戏的概率为 p（厂商只承诺长期均值，不承诺节奏）。相邻两次触发之间的间隔 G（中间隔了多少局）服从几何分布：

P(G = g) = (1−p)g · p　　E[G] = (1−p)/p　　P(G > m+n | G > m) = P(G > n)　← 无记忆性

P(≤N 内触发) = 1−(1−p)N。即使等到平均间隔的 3 倍时长，仍有约 5% 的人什么都没等到——这不是被针对。

怎么读这张实验结果

  • 平均间隔 ≈ (1−p)/p，但个别间隔可以是均值的 5～10 倍，这是几何分布的固有形状。
  • 图 2 的蓝柱始终贴着红色水平线 p 上下抖动：已经等了多久，对下一局毫无加成。
  • 100 万局只需要普通浏览器几秒算完——厂商服务器每秒处理的旋转量比这大几个数量级，任何"冷热规律"都会被规模轻松制造出来。

③ “预测策略”对决：命中率永远 = p

用第②页设定的 p，模拟 10 万局旋转，让 5 种典型“预测方法”在同一份随机序列上押注“下一局会触发免费游戏”。重点看命中率（精确率）：它衡量“当策略说要出时，真的出的比例”。

策略预测次数命中次数命中率（精确率）覆盖率总正确率
无论采用哪种策略——每次都押、连冷后押、刚出过才押、按固定周期押、掷硬币押——“预测会触发”时的真实命中率都在 p 附近波动，统计上没有任何一种能稳定跑赢 p。差异只在于你押得勤不勤（覆盖率），不在于你猜得准不准。

卖“预测软件”的人靠什么让你相信它有效

  • 幸存者截图：几何分布下“连冷后恰好出”的样本天然大量存在，只晒赢的那批即可。
  • 模糊话术：“即将进入放分周期”不可证伪，出了归功、不出继续等。
  • 合谋收费：软件费 + 代理返水，你的亏损就是对方的收入。
  • 本页实验可以反复点，换种子、换 p、换阈值，结论不变。

一个判别问题

如果真有人能提前知道免费游戏何时触发，他为什么要把一台印钞机按月租卖给你，而不是自己默默使用？因为软件本身一文不值，你的订阅费才是他的收益。

在数学上，能稳定把命中率从 p 提高到 p+ε，意味着你掌握了 RNG 的内部状态——那不是“预测”，而是入侵服务器或破解 CSPRNG，属于刑事犯罪，且正规平台的审计与风控会立刻发现异常。
